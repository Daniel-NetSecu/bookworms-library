# 书虫 · 双语阅读书房

137 册，入门级到第 6 级。静态 HTML 阅读站，书名/章节搜索、分级筛选、三级目录、章节前后导航、阅读位置记忆与移动端目录。

内容来源：用户本地提供的 137 册 EPUB。原书文字、插图、版权页和译文保留；未收录压缩包中与该合集无关的文件。

部署：GitHub Actions → GitHub Pages。推送 main 后自动发布。无需外部 CDN。

本地预览：`python -m http.server 8098`。

`build.py` 从 EPUB NCX 目录生成 catalog.json，并添加响应式阅读样式。原始 EPUB 已拆成按需访问的章节，避免一次下载 148 MB 合集。
